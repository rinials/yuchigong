|-----|------|
| **用例名称** | 全球多方沉浸式协作会议 |
| **用例编号** | UC-5.1-A |
| **所属用例族** | 沉浸式通信 |
| **描述** | 分布于全球不同地点的多名用户通过6G网络和XR头显设备，在共享全息虚拟会议空间中实时交互，体验与面对面会议相同的沉浸感和临场感 |

| **服务流程** | 1. 发起方通过应用创建沉浸式会议会话 → 2. 网络为所有参与者建立多路低时延连接 → 3. 各端采集三维音视频和动作数据 → 4. 边缘节点实时渲染共享虚拟空间 → 5. 各端接收并显示其他参与者的全息形象 → 6. 支持手势、语音、白板等实时交互 → 7. 会议内容实时记录并可回放 |
| **后置条件** | 会议内容已归档；所有参与者恢复各自独立会话 |
| **下行数据速率需求** | ≥ 100 Gbps（多路全息流） |
| **端到端时延需求** | < 1 ms |
| **可靠性需求** | 99.999% |
| **定位精度需求** | < 1 cm（手势捕捉） |
