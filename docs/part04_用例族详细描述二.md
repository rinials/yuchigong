## 5.6 全息与沉浸式通信用例（详细）

### 用例 5.6-A：实时全息远程呈现（Holographic Telepresence）

| 项目 | 描述 |
|-----|------|
| **用例名称** | 实时全息远程呈现 |
| **用例编号** | UC-5.6-A |
| **所属用例族** | 全息与沉浸式通信 |
| **描述** | 将远端人物或物体的完整光场数据实时采集并传输，在接收端通过全息显示设备重建逼真的三维全息影像，实现"人物跨空间实时在场"的通信体验 |
| **参与者** | 发送端（光场采集阵列）、接收端（全息显示设备）、6G网络、光场编解码平台 |
| **前提条件** | 发送端配备多角度光场摄像机阵列；接收端具备全息显示能力；网络提供Tbps级带宽和<1 ms时延 |
| **服务流程** | 1. 发送端光场摄像机阵列捕捉完整三维影像 → 2. 光场数据实时压缩编码 → 3. 通过6G网络传输至接收端 → 4. 接收端实时解码重建光场 → 5. 全息显示设备投射三维影像 → 6. 支持接收方从任意视角观察全息影像 |
| **后置条件** | 通话记录已保存（按需）；会话流量统计完成 |
| **数据速率需求** | ≥ 1 Tbps（未压缩光场）；≥ 100 Gbps（压缩后） |
| **端到端时延需求** | < 1 ms |
| **可靠性需求** | 99.999% |
| **帧率需求** | ≥ 120 fps |
